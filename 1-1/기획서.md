# 🎬 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나 (대상)
* 불특정 다수가 접속해서 자유롭게 사용하는 공개용 웹페이지

## 2. 무엇을 하려고 (목적)
* 사용자들의 순수 취미 및 재미를 위해

## 3. 화면과 동작 (UI 및 상호작용)
* **영화 이동:** 마우스 '드래그 앤 드롭(Drag & Drop)' 방식을 사용하여 영화 이미지를 등급 칸으로 이동
* **커스텀 기능 (영화):** 사용자가 직접 새로운 영화를 추가하거나 기존 영화를 제거할 수 있음
* **커스텀 기능 (등급):** 사용자가 직접 등급(티어) 행을 추가하거나 제거할 수 있음
* **결과 저장:** 완성된 티어리스트 화면을 이미지 파일로 저장(다운로드)할 수 있음
> 💡 **아직 정해지지 않은 부분 (추후 결정 필요):** 
> * 전체적인 화면의 색상이나 디자인 테마
> * '추가/제거' 버튼이나 '이미지 저장' 버튼이 화면 어디에 위치할지 (레이아웃)

## 4. 필요한 자료 (데이터)
* **기본 데이터:** 개발자가 사전에 직접 지정해 둔 기본 영화 리스트 (이미지 및 제목 등)
* **사용자 데이터:** 사용자가 직접 추가하는 영화 데이터
> 💡 **아직 정해지지 않은 부분 (추후 결정 필요):** 
> * 사용자가 영화를 추가할 때, 내 컴퓨터에 있는 이미지 파일을 업로드(첨부)하는 방식일지, 아니면 인터넷 이미지 주소(URL)를 복사해서 넣는 방식일지

## 5. 완성 기준
* **지원 기기:** PC 환경에서만 정상적으로 화면이 보이고 동작할 것 (모바일 환경은 고려하지 않음)
> 💡 **아직 정해지지 않은 부분 (추후 결정 필요):** 
> * 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 특정 웹 브라우저 호환성 기준
