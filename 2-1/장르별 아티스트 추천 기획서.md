# 장르별 아티스트 추천 웹사이트

## 대상 사용자

- 새로운 음악이나 아티스트를 발견하고 싶은 사람
- 자신이 어떤 음악 장르를 좋아하는지 정확히 모르는 입문자
- 특정 장르의 대표곡을 빠르게 찾아 유튜브로 감상하고 싶은 사용자

## 사용 목적

- 사용자의 취향을 분석하여 적절한 음악 장르를 추천함
- 장르별 대표 아티스트와 곡 정보를 한눈에 확인하고 바로 청취할 수 있도록 도움
## 화면 구성과 동작

- 상단 검색창: 가수 이름이나 장르명을 입력하면 실시간으로 해당 결과가 아래에 필터링되어 표시됨
- 장르 추천 링크: 검색창 바로 아래 "장르 이름을 잘 모르시나요?" 버튼이 있으며, 클릭 시 퀴즈 섹션으로 이동함
- 장르 버튼 목록: K-Pop, Rock, Jazz 등 다양한 장르 버튼이 나열됨. 버튼 클릭 시 해당 장르의 아티스트 리스트가 나타남
- 아티스트 리스트: 아티스트 이름을 클릭하면 아코디언 방식으로 아래에 대표곡 3곡이 펼쳐짐
- 유튜브 버튼: 각 곡 옆에 있는 버튼을 누르면 해당 가수명 + 곡명이 검색된 유튜브 페이지가 새 탭으로 열림

## 필요한 자료

- 장르 별 아티스트 리스트
- 아티스트 별 대표곡
- 사용자가 찾는 장르를 색출하기 위한 질문지 리스트

## 완료 기준

- 장르 버튼을 눌렀을 때 해당 장르의 아티스트 목록이 정확히 출력되어야 함
- 아티스트 클릭 시 대표곡 3곡이 나타나고, 유튜브 버튼 클릭 시 검색 결과 페이지로 연결되어야 함
- "장르 이름을 잘 모르시나요?" 퀴즈를 완료했을 때 결과에 맞는 장르가 추천되어야 함

## 검증 방법

- 검색 기능 테스트: 데이터에 있는 가수 이름을 입력했을 때 해당 가수만 화면에 남는지 확인
- 퀴즈 로직 테스트: 특정 장르에 편향된 답변을 했을 때 예상한 장르가 결과로 나오는지 확인
- 링크 동작 확인: 유튜브 버튼을 눌렀을 때 검색어가 URL에 올바르게 포함되어 전달되는지 확인
