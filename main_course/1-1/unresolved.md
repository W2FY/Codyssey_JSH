## [미해결 1] 공고 URL만 주고 공고 내용을 정리시키기
 
### 원하는 결과
공고 이미지나 텍스트를 따로 붙이지 않고, 채용 공고 URL만 주면 AI가 페이지 본문을 읽어
정해진 표로 정리하는 것. 공고를 매번 캡처하거나 복사하지 않아도 되게 하는 것이 목적이었다.
 
### 시도한 프롬프트
시스템 프롬프트 v2(프로젝트 지침)를 적용한 상태에서 아래 메시지를 보냄
```
아래 채용 공고를 정리해 줘.
- 관심 포지션: IT Infra Management
- 특히 확인하고 싶은 것: 지원 자격, 급여
- 공고: https://psk.recruiter.co.kr/career/jobs/135734
```
 
### 받은 결과
시도 1 (PSK 이미지를 올렸던 기존 대화에서 URL 메시지 전송)
- "링크 페이지에서는 공고 제목("IT Infra 수시모집(인턴, 경력)")만 읽혔고 본문은 나오지 않았어요. 그래서 아래 내용은 첨부하신 이미지를 기준으로 정리했어요."
- URL 본문은 읽지 못했고, 같은 대화에 앞서 올린 PSK 이미지로 표를 채웠다. URL만으로 정리한 결과가 아니다.
시도 2 (v2 프로젝트의 새 대화, 이미지 없이 URL만 전송)
- "공고 페이지의 본문이 직접 읽히지 않아서 브라우저가 필요해요."
- "지금 읽을 수 있었던 건 페이지 정보뿐이에요. 기관명은 피에스케이(주)이고, 공고 제목은 "IT Infra 수시모집(인턴, 경력)"이에요. 지원 자격이나 급여 같은 본문 내용은 확인하지 못했어요."
- 브라우저 연결(Claude 데스크톱 앱, Claude in Chrome)을 하거나, 공고 본문 텍스트나 캡처 이미지를 올려 달라고 안내했다.
- 내용을 지어내지는 않았지만, 표 정리는 하지 못했다.
### 막힌 이유
처음엔 링크만 주면 AI가 알아서 공고를 읽어 올 줄 알았다. 그런데 이 채용 사이트는 브라우저에서
스크립트가 돌아가야 본문이 보이는 구조라서, AI가 URL로 가져온 건 회사명과 공고 제목뿐이었다.
프롬프트를 아무리 바꿔도 AI가 받는 내용 자체가 비어 있으니 해결할 방법이 없었다. 다행히 v2 규칙
덕분에 본문을 지어내지는 않았지만, 결국 내가 공고를 캡처하거나 복사해서 넣어야 했다. AI는
브라우저를 연결하면 읽을 수 있다고 했는데, 그건 프롬프트가 아니라 도구 연결 문제라 이번에는
시도하지 않았다. "링크만 주면 정리"라는 목표는 이루지 못해서 미해결로 남긴다.
