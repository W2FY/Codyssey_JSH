## 수정 기록

### 수정 기록 1
- 발견한 문제: 장르 추천 퀴즈가 "장르 이름을 잘 모르시나요?" 버튼을 클릭하지 않았는데도 메인화면에 표출됨
- AI에게 전달한 요청:장르 추천 퀴즈가 "장르 이름을 잘 모르시나요?" 버튼을 클릭하지 않았는데도 메인화면에 표출됨. 버튼을 눌렀을 때만 표출되도록 변경해서 html코드 보여줘.
- 수정 후 테스트 결과: "장르 이름을 잘 모르시나요?" 버튼을 클릭해야 장르 추천 퀴즈가 표시됨.
- 수정 이유: 장르명을 아는 사람은 장르명을 찾아가는 퀴즈를 볼 필요 없음

### 수정 기록 2
- 발견한 문제: 장르를 선택 시 장르 버튼 목록의 변화가 없어 현재 선택한 장르가 무엇인지 알 수 없음.
- AI에게 전달한 요청: 장르 버튼 목록에서 장르 선택 시 현재 선택한 장르를 연한 초록색으로 표시하도록 수정해줘.
- 수정 후 테스트 결과: 장르 버튼 목록에서 장르 선택 시 선택한 장르가 연한 초록색으로 표시됨
- 수정 이유: 사용자가 장르를 클릭 시 웹의 반응을 확인할 수 있음.

### 수정 기록 3
- 발견한 문제: 장르 검색 후 해당 장르 선택 시 장르 버튼 목록이 검색 전으로 초기화됨.
- AI에게 전달한 요청: 장르 검색 후 해당 장르 선택 시 장르 버튼 목록이 검색 전으로 초기화되는데, 장르를 선택해도 검색 결과는 유지되도록 수정해줘.
- 수정 후 테스트 결과: 장르 검색 후 해당 장르 선택 시 장르 버튼이 초록색으로 바뀌며, 검색 전의 장르 선택 목록으로 돌아가지 않음
- 수정 이유: 검색창에 검색한 결과가 버튼 선택 후에도 유지되어야 함.

### 수정 기록 4
- 발견한 문제: 아티스트 검색 시 장르 버튼 목록이 비어있음
- AI에게 전달한 요청: 아티스트명으로 검색하면 지금은 장르 버튼 목록에 "검색된 장르가 없습니다." 라고 뜨는데 해당 아티스트가 속한 장르를 표시하도록 변경해줘
- 수정 후 테스트 결과: 아티스트를 검색하면 아티스트가 속한 장르명이 장르 선택 목록에 표시
- 수정 이유: 사용자가 해당 아티스트가 주로 다루는 장르를 알고 싶을 수 있기 때문

## 사용자 테스트
- 테스트 참여자와 요청한 작업: 동료에게 검색창에 원하는 아티스트나 장르명을 검색해보라고 요청
- 사용자의 행동과 질문: 아티스트나 장르명으로 검색은 잘 되는데 노래로 검색하면 안돼?
- 받은 피드백: 내가 아는 노래를 검색하고 해당 노래의 아티스트와 장르를 알 수 있으면 좋겠다.
- 반영 내용과 결과: "검색창에 곡 명으로도 검색이 가능하도록 수정해줘. 또한 검색 박스에 입력 하기 전에 디폴트 문구로 "장르, 아티스트, 노래 무엇이든 검색해보세요!" 라는 문구가 있으면 좋겠어. 검색창에 내용을 입력하면 해당 문구는 사라지는 방식으로." 라고 AI에게 전달해 html을 수정했습니다.
